# Как запустить сайт с погодной ведущей

Этот репозиторий теперь содержит два разных проекта:

1. `main.py` — старый скрипт экспорта WeatherCloud в Google Sheets.
2. `site/` — новый статический сайт с погодной ведущей на русском и английском языках.

Для запуска сайта WeatherCloud-логин, Google-ключи и переменные окружения из `main.py` не нужны.

## 1. Быстрый запуск на компьютере

Нужен только Python 3. Если Python уже установлен, выполните из корня репозитория:

```bash
python -m http.server 8000 --directory site
```

После этого откройте в браузере:

```text
http://localhost:8000
```

Важно: не открывайте `site/index.html` двойным кликом как файл `file://...`. Для карты, модульного JavaScript и запросов к погоде нужен локальный HTTP-сервер.

## 2. Что должно работать сразу

После открытия сайта:

1. Выберите язык кнопками `RU` или `EN`.
2. Введите город и страну, например `Москва` + `Россия` или `London` + `United Kingdom`.
3. Выберите период: сейчас, 3 дня или 7–10 дней.
4. Нажмите кнопку прогноза.

Сайт сам обращается к бесплатным внешним сервисам:

- Open-Meteo — геокодинг и прогноз погоды без API-ключа.
- OpenStreetMap через Leaflet — карта на фоне.
- Web Speech API в браузере — озвучивание прогноза.

## 3. Требования для работы

На компьютере или сервере, где открыт сайт, должны быть доступны внешние адреса:

- `https://api.open-meteo.com`
- `https://geocoding-api.open-meteo.com`
- `https://tile.openstreetmap.org`
- `https://unpkg.com` — библиотека Leaflet подключена с CDN.

Если корпоративная сеть, хостинг или прокси блокирует эти домены, карта или прогноз не загрузятся. В таком случае нужно разрешить эти домены либо заменить CDN/тайлы/API на собственный backend или другого провайдера.

## 4. Публикация в интернет

Для облачного деплоя теперь есть отдельная инструкция: [`CLOUD_DEPLOY_RU.md`](CLOUD_DEPLOY_RU.md). Там описаны GitHub Pages, Netlify, Cloudflare Pages и Vercel.

Так как `site/` — обычный статический сайт, его можно выложить почти на любой статический хостинг.

### Вариант A: Netlify / Vercel / Cloudflare Pages

1. Подключите Git-репозиторий к хостингу.
2. Укажите папку публикации: `site`.
3. Build command оставьте пустым — сборка не нужна.
4. Deploy command / output directory: `site`.

### Вариант B: любой VPS или обычный хостинг

Скопируйте содержимое папки `site/` в публичную директорию сайта, например `public_html/` или `/var/www/html/`.

### Вариант C: GitHub Pages

GitHub Pages обычно публикует корень репозитория или папку `docs/`. Для него можно либо настроить отдельную ветку, либо скопировать `site/` в `docs/` и выбрать `docs` как источник публикации.

## 5. Что ещё не является готовым продакшеном

Текущий сайт — рабочий прототип. Для полноценного продукта нужно дополнительно сделать:

- заменить CSS-аватар на сгенерированную и лицензированную взрослую вымышленную AI-модель;
- добавить rig/lip-sync или видео-пайплайн, чтобы модель реалистично двигалась и синхронизировала губы;
- подключить стабильный TTS-сервис для одинакового голоса на всех устройствах;
- добавить backend-прокси для кеширования погоды, лимитов, ключей платных сервисов и защиты от блокировок;
- для большого трафика использовать коммерческий tile provider или собственные OpenStreetMap-тайлы, а не публичные тайлы OSM напрямую.

Подробный план по AI-модели и анимации описан в `site/AI_AVATAR_PLAN.md`.

## 6. Частые проблемы

### Страница открылась, но карта пустая

Проверьте интернет и доступность `unpkg.com` и `tile.openstreetmap.org`. Также откройте консоль браузера: если Leaflet не загрузился, будет ошибка про `L is not defined`.

### Город не находится

Попробуйте ввести страну на английском или более точное название, например `New York` + `United States`.

### Прогноз не загружается

Проверьте доступность `api.open-meteo.com` и `geocoding-api.open-meteo.com`. В некоторых окружениях запросы к внешним API могут блокироваться прокси или firewall.

### Голос не звучит

Озвучивание зависит от браузера и доступных системных голосов. В Chrome/Edge обычно работает лучше всего. Если Web Speech API недоступен, текст прогноза всё равно показывается в облачке.
